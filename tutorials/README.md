## Before you start

- New account? [Sign in](../start/sign-in.md) first.
- Already have a working bot? [Make a test copy](../app/copy-bot.md) and configure a separate Telegram token before experimenting.
- New to code? Start with [JavaScript basics](../bjs/javascript-basics.md) before the data route.

## Looking for one task?

Use [the recipe catalogue](../guides/recipes.md) for a single feature or [the BJS reference](../bjs/README.md) for a method and its contract. These routes do not require you to finish every earlier tutorial if you already meet the preparation requirements.
